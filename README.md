# Telegram RPG Game Bot

A feature-rich Telegram RPG bot built with Python and Aiogram.

## Features

* Multi-user player system
* Persistent save data using JSON
* RPG battle system
* Boss battles
* Inventory system
* Equipment system
* Shop system
* Daily rewards
* XP and leveling system
* AI-generated quests
* Rare loot drops
* Health and potion system

## Commands

* /start
* /stats
* /quest
* /daily
* /heal
* /inventory
* /equip
* /shop
* /battle
* /boss

## Tech Stack

* Python
* Aiogram
* Telegram Bot API
* JSON Storage
* Ollama AI
